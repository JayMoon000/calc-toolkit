### 2. 유지보수 및 운영 가이드 (Operation Workflow)

1. **평상시 (완전 무관리)**
   - GitHub Actions가 매주 월요일 오전 9시(KST) 법제처 개정안을 자동 크롤링하고 Gemini가 영향도를 분석합니다.
   - 변경 사항이 없을 경우 별도의 작업이 전혀 필요하지 않습니다.

2. **법 개정 알림 수신 시 (Zero-effort 대응)**
   - 텔레그램으로 수치 변경 권고 메시지 수신.
   - `run_admin.bat` 실행 (브라우저 관리 패널 자동 호출).
   - 카드 폼에서 변경된 항목(시급, 4대보험, 이자세율 등) 입력 후 `[최종 저장]` 클릭.
   - 터미널에서 1줄 배포 실행:
     `git commit -am "chore: update rates" && git push origin main`
   - Vercel 무중단 자동 재배포 완료 (약 30초 소요).

3. **애드센스 심사 모니터링**
   - 심사 기간(3일~2주) 동안 Vercel DNS 및 도메인 구조 유지.
   - 심사 완료 알림 메일 수신 시까지 추가 코드 변경 없이 대기.
